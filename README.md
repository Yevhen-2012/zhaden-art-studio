# ZHADEN ART STUDIO

Статичний сайт, перенесений з Webflow-проєкту `Sarny-history-museum`.
Джерело: `sarny-history-museum.webflow.zip`, експорт від 24 вересня 2026 року.

## Локальний запуск

Потрібен Node.js 18 або новіший. Додаткові пакети встановлювати не потрібно.

```sh
npm start
```

Відкрити http://127.0.0.1:4173. Зупинити сервер: Ctrl+C.
Сервер підтримує також адреси без `.html`, наприклад `/contacts`.

## Перевірка та файли для хостингу

```sh
npm run check
npm run build
```

Перевірка охоплює локальні файли, регістр назв для Linux-хостингу, якорі,
CSS-ресурси, JSON галерей та синтаксис вбудованого JavaScript.
Готові публічні файли копіюються у `dist/`. Збірка не потребує мережі.
Папка `dist/` генерується й не додається до Git.

## Структура

- `index.html` — головна.
- `team.html`, `portfolio.html`, `architecture.html`, `interior-design.html`,
  `art-gallery.html`, `contacts.html` — інші сторінки.
- `css/`, `js/`, `images/`, `fonts/`, `documents/` — ресурси експорту.
- `js/site-config.js` — публічна адреса сервісу приймання форм.
- `scripts/` — локальний сервер, перевірка та копіювання публічних файлів.

Початкова папка `museum/` з окремою колекцією фото збережена без змін;
сайт використовує `images/`. `museum/` не включена у Git або `dist/`.
Чернетка `gallery-template` у ZIP відсутня. Експорт не містить CMS-списків;
це не підтверджує відсутність окремих CMS-даних у вихідному Webflow-проєкті.

## Що виправлено під час перенесення

- Посилання Customer reviews ведуть на локальну головну, а не на Webflow.
- Виправлено посилання Our Team, Customer reviews і Contacts у футері.
- 33 великі зображення галерей використовують локальну папку `images/`.
- Видалено помилкове оголошення `OFL.txt` як шрифту; саму ліцензію збережено.
- Додано `lang="en"`; обмежено горизонтальний вихід анімованих блоків портфоліо.
- Збережено стилі, слайдери, lightbox і Webflow-анімації.

## Контактні форми — потрібне налаштування

Git та статичний хостинг самі не приймають заявки. До налаштування сервісу
кнопки надсилання вимкнені, а біля форми показується email із вихідного сайту.
Форма не надсилає дані до Webflow й не показує удаване повідомлення про успіх.

У `js/site-config.js` потрібно вказати публічний HTTPS endpoint провайдера,
який підтримує звичайний HTML POST і власну сторінку підтвердження.
Після цього обидві форми активуються. Не додавайте у цей файл секрети.
Назви полів із Webflow: `name`, `email`, `field` (телефон), `field-2` (повідомлення).
Email одержувача, антиспам та підтвердження налаштовуються у сервісі форм.
Реальне надсилання ще не перевірене: провайдера не обрано.

## Зовнішні залежності

Google Fonts (Montserrat і Droid Sans), Web Font Loader, jQuery, SmoothScroll,
GSAP і ScrollTrigger залишені на CDN, як у вихідному експорті.
Для їх завантаження браузеру потрібен інтернет. Власні фото, CSS,
Webflow runtime та шрифти з ZIP зберігаються локально.
Статична копія не синхронізується автоматично з подальшими змінами у Designer.

та їх перенаправлення на обраному хостингу.
